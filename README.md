# Apache-Tomcat
A simple HTML web application created and run using Apache Tomcat 11.0.25.
# Experiment: Installation and Configuration of Apache Tomcat

**Aim:** To install and configure Apache Tomcat and create and run a simple web application using an HTML page.

**Software Requirements:**
1. JDK
2. Apache Tomcat 11.0.25
3. Visual Studio Code
4. Web Browser

**Theory:** Apache Tomcat is a web server and Servlet container used to run Java web applications. It serves web pages and handles HTTP requests from clients.

**Procedure:**
1. Downloaded and extracted Apache Tomcat.
2. Created a folder named `MyWebApp` inside the `webapps` directory.
3. Created an `index.html` file inside `MyWebApp`.
4. Added HTML content to the file and saved it.
5. Started the Tomcat server using `startup.bat`.
6. Opened `http://localhost:8080/MyWebApp/` in the browser.
7. Verified that the web page was displayed successfully.

**Result:** Apache Tomcat was successfully started, and a simple HTML web application was created and executed.
